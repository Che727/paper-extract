# paper-extract

## 描述

从论文 PDF 中自动提取元信息和结构化内容，写入飞书多维表格「论文阅读知识库」。

## 触发方式

**触发词**：`/paper-extract`、`开始总结论文`、`提取论文`

```
/paper-extract <record_id>     # 处理指定记录
/paper-extract --all            # 处理所有未提取的记录
开始总结论文                     # 同上，处理最新上传的未提取论文
```

## 前置条件

- 飞书 CLI (`lark-cli`) 已安装并登录
- Python 3 + pdfplumber 已安装
- Anthropic API Key 已配置在 `.env` 文件
- 飞书表格存在且有 PDF 附件

## 工作流

### Step 1: 定位目标记录

**如果用户指定了 `<record_id>`：**
```bash
lark-cli base +record-get --base-token SfvxbGyIKa0TuustcOicJxaDnod \
  --table-id tbl5zIayFMJlAEsX --record-id <record_id> --as user
```

**如果用户指定了 `--all`：**
查找 PDF附件字段不为空、但论文标题字段为空的记录（即未提取的记录）：
```bash
lark-cli base +record-list --base-token SfvxbGyIKa0TuustcOicJxaDnod \
  --table-id tbl5zIayFMJlAEsX --as user --format json
```
从结果中筛选出有待提取 PDF 的记录。

---

### Step 2: 下载 PDF 附件

```bash
# 先检查 PDF附件字段的附件信息
lark-cli base +record-get --base-token SfvxbGyIKa0TuustcOicJxaDnod \
  --table-id tbl5zIayFMJlAEsX --record-id <record_id> --as user

# 下载附件
lark-cli base +record-download-attachment --base-token SfvxbGyIKa0TuustcOicJxaDnod \
  --table-id tbl5zIayFMJlAEsX --record-id <record_id> \
  --field PDF附件 --output ./data/papers/<record_id>.pdf --as user
```

---

### Step 3: 提取 PDF 文本

```bash
python3 scripts/pdf_extract.py ./data/papers/<record_id>.pdf --core-only
```

检查输出：
- 如果 `has_text_layer: false`（总字符 < 100），判定为扫描版 PDF
- 如果是扫描版，跳转到 [失败处理：扫描版PDF](#扫描版pdf)

如果是硕博论文（>50页），使用 `--core-only` 只提取核心章节(摘要→绪论→方法→实证→结论)。
如果是期刊论文（<30页），省略 `--core-only` 提取全文。

提取结果保存在 `./data/papers/<record_id>_core.txt`。

创建新标签前检查已有标签。以下同义词必须复用已有标签：

## 提取要求
- 核心问题：区分「研究目标」和「核心问题」。目标是「做了什么」，核心问题是「解决什么根本痛点」。要求拆解为子问题链
- 背景：研究背景、问题缘起、现实问题描述
- 国内综述：国内研究脉络、主要学者/团队、研究进展
- 国际综述：国外研究脉络、国际理论与案例
- 政策：涉及的政策文件、规划文件、法规
- 方法：整体方法论+数据来源+样本量+分析工具+技术路线+案例选择标准
- 结论：严格区分「现状描述」vs「研究结论」、「分析问题」vs「解决问题」
- 方法论贡献：新框架？改进方法？新数据源？新视角？
- 优点：逻辑/方法/写作三个层面，禁止空洞赞美
- 不足：方法论/逻辑/表述/实操四类缺陷
- 对我论文的借鉴：直接迁移/调整后用/避坑
- 理论：论文使用了什么理论来解释问题？标注提出者、核心概念、应用方式
- 引用：可直接引用的原文段落，标注页码范围，3-5处

每个详情的长度控制在 500-2000 字。如果论文确实没有某维度内容（如无政策相关内容），详情填"(无相关内容)"，标签字段留空数组[]。

## 失败处理

### 扫描版 PDF

如果 `pdf_extract.py` 返回 `has_text_layer: false`：

```bash
lark-cli base +record-upsert --base-token SfvxbGyIKa0TuustcOicJxaDnod \
  --table-id tbl5zIayFMJlAEsX --record-id <record_id> \
  --json '{"fields":{"我的笔记":"⚠️ 扫描版PDF，无法自动提取文字。建议手动填写或使用OCR工具。"}}' --as user
```
然后终止处理，告知用户。

### 某维度无内容

如果 AI 返回某维度详情为 "(无相关内容)"：
- 标签字段写入空数组 `[]`
- 详情字段写入 `"(无相关内容)"`
- 这是正常情况，不视为错误

### 提取中断（断点续传）

重新运行 `/paper-extract <record_id>` 时：
1. 先读取该记录当前状态
2. 跳过已有值的字段，只补充空白字段
3. 如果论文标题已存在 → 跳过 Round 1，直接进入 Round 2
