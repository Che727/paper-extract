# Paper Extract — 论文 AI 提取助手

上传论文 PDF → AI 自动提取结构化内容 → 写入飞书多维表格。让论文阅读从"翻 PDF + 手动笔记"变成"上传即提取、表格化管理"。

## 核心功能

- **一张表管理所有论文**：飞书多维表格存储，支持字段筛选、多选标签、全文检索
- **AI 全维度提取**：上传 PDF 后自动提取元信息 + 14 个内容维度，含导师论文阅读方法论框架
- **标签化 + 详情化双字段**：每个维度配有标签（多选）和详情（Markdown），可快速筛选也可深入阅读
- **同义词自动去重**：标签创建时智能复用已有选项，避免"POE"和"使用后评价"并存
- **断点续传**：提取中断后重跑自动跳过已完成字段

## 快速开始

### 1. 环境要求

- Python 3.10+
- Node.js 22+（飞书 CLI 依赖）
- 飞书开放平台应用（需 Base 权限）
- Anthropic API Key（或使用 Claude Code 内置提取）

### 2. 安装

```bash
# 安装 Python 依赖
pip install pdfplumber python-dotenv

# 安装飞书 CLI
npm install -g @larksuite/cli
npx skills add larksuite/cli -y -g

# 配置飞书 CLI
lark-cli config init --app-id <your_app_id> --app-secret-stdin
lark-cli auth login --recommend
```

### 3. 配置

```bash
cp .env.example .env
# 编辑 .env 填入 ANTHROPIC_API_KEY
```

### 4. 创建飞书多维表格

在飞书开放平台创建 Base 并配置字段，或使用 `lark-cli base +base-create` 命令创建。字段方案见下方。

### 5. 使用

1. 在飞书表格中上传论文 PDF 到"PDF附件"字段
2. 在 Claude Code 中运行：

```
/paper-extract <record_id>    # 处理指定记录
开始总结论文                    # 处理最新未提取的论文
```

## 飞书多维表格字段

### 元信息字段

| 字段名 | 类型 | 说明 |
|--------|------|------|
| PDF附件 | 附件 | 上传论文 PDF |
| 论文标题 | 文本 | AI 提取 |
| 作者 | 文本 | AI 提取 |
| 年份 | 数字 | AI 提取 |
| 期刊/来源 | 文本 | AI 提取 |
| 学校 | 文本 | AI 提取 |
| 关键词 | 多选 | AI 提取，含同义词去重 |

### 内容提取字段（标签 + 详情 配对）

| 标签字段(多选) | 详情字段(多行文本) | 提取内容 |
|---------------|-------------------|---------|
| 背景标签 | 背景详情 | 研究背景与问题 |
| 国内综述标签 | 国内综述详情 | 国内研究现状 |
| 国际综述标签 | 国际综述详情 | 国外研究现状 |
| 政策标签 | 政策详情 | 政策/规划文件 |
| 方法标签 | 方法详情 | 研究方法、数据来源、技术路线 |
| 结论标签 | 结论详情 | 核心发现与结论 |
| 引用标签 | 引用详情 | 可直接引用的原文段落 |

### 深度分析字段

| 字段名 | 类型 | 对应分析维度 |
|--------|------|-------------|
| 核心问题 | 多行文本 | 核心研究问题 + 子问题链 |
| 方法论贡献 | 多行文本 | 方法论层面的独特贡献 |
| 优点 | 多行文本 | 逻辑/方法/写作三个层面的可借鉴之处 |
| 不足 | 多行文本 | 方法论/逻辑/表述/实操四类缺陷 |
| 对我论文的借鉴 | 多行文本 | 直接迁移/调整后用/注意避坑 |

### 手动字段

| 字段名 | 类型 | 说明 |
|--------|------|------|
| 相关度 | 单选 | ⭐1-5 与研究的相关程度 |
| 我的笔记 | 多行文本 | 自由笔记 |

## 技术架构

```
论文 PDF
  │
  ├── pdfplumber 提取全文（支持章节识别、硕博论文核心章节过滤）
  │
  ├── Claude AI 两轮提取
  │   ├── Round 1: 元信息（标题/作者/年份/学校/关键词）
  │   └── Round 2: 14 个内容维度（标签+详情+深度分析）
  │        └── 标签去重：先读已有选项 → 同义词判定 → 复用或新建
  │
  └── lark-cli 写入飞书多维表格
```
